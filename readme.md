# 💼 Personal Portfolio Website

[![Live Site](https://img.shields.io/badge/Live%20Site-Visit-0db7ed?style=flat-square&logo=vercel&logoColor=white)](https://next-js-animated-portfolio-website.vercel.app/)

A modern, animated **developer portfolio website** built with **Next.js**, **TailwindCSS**, and **Framer Motion** — designed to showcase my work, skills, and contact information in a professional, engaging way.

---

## ✨ Highlights

- 🎨 **Dark Theme Design** with a consistent and elegant modern UI
- 🧭 **6 Navigable Pages** with smooth scroll and page transitions
- ⚡ **Framer Motion Animations** for interactive UI and engaging user experience
- 🧵 **App Router Integration** with improved performance and parallel rendering
- 🚀 Achieved a **10% boost** in rendering performance through server-optimized layouts
- 💡 **Fully Responsive** and mobile-friendly design

---

## 🖥️ Pages Overview

| Page            | Description                                                  |
|-----------------|--------------------------------------------------------------|
| `/about`        | Learn more about me, my skills, and developer background     |
| `/services`     | Overview of the services I offer as a fullstack developer    |
| `/work`         | Portfolio of featured projects with interactive previews     |
| `/testimonials` | Reviews and feedback from clients, colleagues, and mentors   |
| `/contact`      | Contact form + ways to reach me (email, socials, etc.)       |

---

## 🧑‍💻 Technologies Used

### Frontend

- **Next.js 13+** – App Router, server components, image optimization
- **TypeScript** – Strong typing for maintainability
- **Tailwind CSS** – Utility-first CSS for consistent design
- **Framer Motion** – Smooth page transitions and component animations
- **React Icons** – Iconography for technologies and UI

## 📦 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/puureya2/Next.js-Animated-Portfolio-Website
cd next-js-animated-portfolio-website

# 2. Install dependencies
npm install

# 3. Run the development server
npm run dev

# 4. Open your browser at
http://localhost:3000
