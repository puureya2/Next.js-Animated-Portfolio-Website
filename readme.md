# Animated Portfolio Website

[![Live Site](https://img.shields.io/badge/Live%20Site-Visit-0db7ed?style=flat-square&logo=vercel&logoColor=white)](https://next-js-animated-portfolio-website.vercel.app/)

This is a **personal portfolio website** built with **Next.js** and **Framer Motion**, designed to showcase my skills as a front-end and fullstack developer. It features smooth animations, responsive design, and a clean layout to present my professional background, services, projects, and more.

---

## 🚀 Features

- ✨ Built with **Next.js 13+**
- 🎯 Smooth, interactive **Framer Motion** animations
- 📱 Fully **responsive** for all screen sizes
- ⚡ Optimized and fast with Next.js's built-in performance tools
- 🧑‍💻 Developer-focused: Clear code structure and reusable components

---

## 🖥️ Pages Overview

| Page         | Description                                                   |
|--------------|---------------------------------------------------------------|
| `/about`     | Learn more about who I am, my skills, and my experience       |
| `/services`  | A breakdown of services I offer as a fullstack developer      |
| `/work`      | A portfolio of my past projects with visual previews          |
| `/testimonials` | Client and peer feedback on working with me               |
| `/contact`   | A form and contact info for reaching out                      |

---

## 🧑‍💻 Technologies Used

- **Next.js** – React framework for building optimized web apps
- **Framer Motion** – Animation library for React
- **Tailwind CSS** – Utility-first CSS framework for styling
- **React Icons** – Icon library used for technology and UI icons

## 📦 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/puureya2/Next.js-Animated-Portfolio-Website
cd next-js-animated-portfolio-website
npm install
npm run dev
Visit http://localhost:3000 to view the website locally.
Note: No environment variables are required. All assets are included in the project.

.
├── components/        # Reusable UI components (e.g. Avatar, Circles)
├── pages/             # App routes (about, services, work, etc.)
├── public/            # Static assets
├── styles/            # Global styles and Tailwind config
├── variants.js        # Framer Motion animations
├── package.json       # Project metadata and scripts
